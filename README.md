# PRO KAYAK FISHING

New foundation for the Tunisia-focused kayak fishing application.

This is intentionally **not** the old monolithic HTML project. The application separates map rendering, marine data, fishing analysis, kayak planning and offline storage.

Reference foundations reviewed:
- Pelorus Nav: marine chartplotter architecture, MapLibre, PMTiles, offline-first design, GPS and testing.
- OpenTides: weather/marine map layers, tap-to-read, Open-Meteo Marine, fishing ratings and resilience patterns.

License note: source projects are referenced as architectural inspiration/components only after checking their licenses; verify each dependency/license before copying source code into production.
